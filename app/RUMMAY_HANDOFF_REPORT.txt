The core game loop supports 3 players (1 Human, 2 AI). 
Currently Implemented & Working:

5. CURRENT GAME FLOW
====================
Levels 1–6 Flow:
1. Draw: Player takes from Stock or accepts a "To You" discard.
2. Hand Organization: Uses Wood Rack, Pocket, or Expanded Hand to sort cards.
3. Action Phase (Play/Discard): 
   - If not down: Player can "Go Down" via MeldBuilder if hand meets contract.
   - If down: Player can "Play On" to any public table melds.
4. Discard: Player selects 1 card to discard.
5. Rummay Check: Engine verifies if discard was playable. If yes, RUMMAY! dialog fires.
6. Buy Priority: Out-of-turn players are offered the discard + penalty stock draw.
7. Next Turn: Control passes to next player.

Level 7 Flow:
1. Draw: Player takes from Stock or "To You" discard.
2. Hand Organization: (Same as above)
3. Action Phase (THAT DID IT!): 
   - Player CANNOT standard "Go Down". 
   - Player evaluates if entire hand can form exactly 3 Runs with ZERO leftovers.
   - If true, taps "THAT DID IT!". 
4. Reveal & Win: Dialog verifies permutations. On confirm, player reveals hand, scores 0, opponents take penalty points, and game ends. (No discard phase).

6. KNOWN BUGS / UNFINISHED ITEMS
================================
- UI Drag-and-Drop to Pocket: Cards cannot be dragged directly into the Pocket button on the rack. Must be clicked and moved via the menu.
- Joker Rummay ambiguity: If a player discards a Joker, it is universally playable. The engine currently flags this as a RUMMAY! penalty. Needs authoritative rule clarification on discarding Jokers.
- AI Level 7 Visual Flow: The AI will correctly calculate a Level 7 win, but instantly transitions the game state. It does not spawn a "Reveal" dialog for the human to watch them lay it down—it just ends the game via toast/status message.
- Stock Deck Exhaustion during Buys: If the stock deck runs out while distributing penalty cards for multiple Buys, the engine reshuffles the discard pile, but edge cases around exactly 0 cards remaining could crash the state.
- Empty Pocket Win: The Level 7 UI filters active cards. If a user tries to win Level 7 while cards are pocketed, the validation might reject it (since total hand count includes the pocket). Users must unpocket cards to win.
